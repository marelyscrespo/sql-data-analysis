# SQL and Data Analysis Projects

This repository contains a collection of data analysis projects using SQL and Python. The projects explore real-world datasets to answer practical questions through data cleaning, querying, statistical analysis, and visualization.

## Projects

### 1. Paris Urban Mobility: A SQL Data Analysis Project

**Tools:** SQL, SQLite, Python, Pandas, Matplotlib

Analysis of bicycle traffic counts and Vélib' station locations in Paris.

Questions explored:
- How does bicycle traffic vary by day of the week?
- Which Vélib' stations have the highest capacity?
- Is there a relationship between bicycle traffic and the location or capacity of Vélib' stations?

**Data sources:**
- [Paris Bicycle Traffic Counts](https://opendata.paris.fr/explore/dataset/comptage-velo-donnees-compteurs/)
- [Vélib' Station Locations](https://opendata.paris.fr/explore/dataset/velib-emplacement-des-stations/)

**Project folder:** `01-paris-urban-mobility/`
